# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-10-06

First tagged candidate, pinned by the maintainer's first controlled
consumer test. It remains a `LOCALLY_VALIDATED_CANDIDATE`, not a
Gate-I-exit release; see `docs/validation-status.md`.

- Implement the narrow 13-input `pre`, `post`, and `status` role contract.
- Add bounded Docker CLI discovery, canonical comparison, lifecycle state,
  retention, replay/conflict handling, and secure atomic POSIX persistence.
- Add deterministic ASCII report modeling and collision-safe image/container
  presentation.
- Add bounded controller-side validation, result sanitization, failure
  envelopes, and quiet one-task execution.
- Add frozen conformance fixtures with implementation-binding tests, a
  daemonless Molecule scenario, direct local-Ansible, replay, multihost, and
  callback harnesses, guarded opt-in live-Docker tests, and synthetic,
  real-filesystem, and live discovery performance measurements.
- Retain field-local partial Docker evidence, enforce strict line protocols
  and absolute validation anchors, bound host projections, and expand
  deterministic failure-path and callback-output proofs.
